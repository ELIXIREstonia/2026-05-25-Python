# Islander Data

`Islander_data.csv` is used in the pandas and visualisation notebooks as a small teaching dataset for tabular data handling and exploratory plotting.

The notebooks load this local copy first. If the local file is unavailable, they use the raw copy from this course repository so the materials still work in Colab.

Source:

Ahn, Steve. *Memory Test on Drugged Islanders Data*. Zenodo, 2025. DOI: [10.5281/zenodo.15369169](https://doi.org/10.5281/zenodo.15369169).
